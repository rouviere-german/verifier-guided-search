# Claims and evidence

Every claim the README makes maps to a test, a bench script or a CI job below.
`scripts/check_baseline.py` fails if a backticked reference here points at a file, test function or CI
job that does not exist, so this table cannot rot quietly.

Local commands run offline with no API key. Rows marked **CI** are verified only in GitHub Actions
(they need Docker or a scanner that is not installed locally).
